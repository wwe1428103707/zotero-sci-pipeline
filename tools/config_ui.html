▶ 运行管线

手动触发管线各个阶段

阶段 1：入库与分级

RSS + 数据库检索 → 去重合并 → AI 分级(A/B/C/D)

完整管线（Stage 1-4 + PDF 下载）

入库分级 → Zotero 写回 → 标题翻译 → Excel 导出 → PDF 自动下载

常用管线（Stage 1-4）

入库分级 → Zotero 写回 → 标题翻译 → Excel 导出（不含 PDF 下载）

ℹ 操作说明

默认范围：系统默认仅处理最近一次管线执行批次（即最新日期子集合，如 2026-05-30），避免遍历全部文献池。
自定义目录：如需指定其他目录，点击「浏览 Zotero 目录」按钮，从 Zotero 客户端目录树中选择目标集合。
翻译流程：扫描选中集合 → 检测未翻译论文 → 自动翻译中文标题 → 写回 Zotero shortTitle
下载流程：扫描选中集合 → 按分级过滤 → 提取 DOI/arXiv ID → Sci-Hub/arXiv 下载 PDF → 附件写回 Zotero
